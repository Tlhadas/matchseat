# MatchSeat

MatchSeat is a web app for finding available football tickets in London.

The goal is to make it easier to find tickets that are actually available, understand the real total price, and identify suitable options for families and children.

## Initial MVP

The first version will focus on:

* London football clubs
* Official ticket sources only
* Adult and junior ticket prices
* Under-16 / junior eligibility rules
* Membership requirements
* Ticket availability
* Seats together where this information is available
* Direct links to official club ticket pages
* Search by date, budget, number of adults, and children's ages

## First Club

The first club integration will be Fulham FC.

The initial goal is to answer a simple question:

> Can I buy one adult ticket and one junior ticket for this match, how much will it cost, and where can I buy them?

## Planned Tech Stack

* Next.js
* TypeScript
* PostgreSQL
* Vercel
* Club-specific ticket connectors

## Status
